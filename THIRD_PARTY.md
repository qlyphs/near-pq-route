# Third-party code and attribution

- `core/pq87.c` is a research ML-DSA-87 verifier following FIPS 204 and the structure of the pq-crystals
  reference (commit `d35ba3fe5449bee3e6d43e1f296c3ca818bd36be`, public domain / CC0, Apache-2.0 or GPL-2.0;
  the public-domain option is used). The zetas are generated mathematically (`core/zetas.inc`).
  `core/keccak_round.inc` is generated by `scripts/gen_keccak.py` from the FIPS 202 round definition.
- `tests/vecgen/` vendors pq-crystals reference files (same commit and licenses, `LICENSE.pq-crystals`).
  Its `sign.c` is modified to produce adversarial boundary vectors for tests; it is never part of a release.
- `program/solana_abi.h` is a modified subset of the Agave/Solana C SDK headers (v2.1.0, Apache-2.0,
  Solana Labs and Anza contributors). Its syscalls are declared as SBPF v3 static syscalls (murmur3 hash of
  the syscall name).
- `toolchain-sbfv3/c/sbf.ld` is the `link-script` of the `sbpfv3-solana-solana` Rust target shipped in
  Solana platform-tools v1.57 (Apache-2.0).
- External tools, not redistributed: OpenSSL (test reference verifier), Solana CLI and platform-tools,
  Python with `cryptography` (Ed25519 for transaction fees only), Node, and the Qlyphs extension sources
  with `@noble/post-quantum`, `@noble/hashes`, `@scure/bip39` and `@quantus-network/wasm`, which the signer
  in `wallet/` loads after checking their content hashes.

- The Guardian demo Worker (`demo/`) bundles `@noble/post-quantum` 0.7.1 (ML-DSA-87 signing for the demo
  signers), `@noble/curves` 1.8.1 (ed25519) and `@noble/hashes` 1.7.1, all MIT, Paul Miller. The tests use
  `near-workspaces` and `near-api-js` (MIT/Apache-2.0), not redistributed.

Original files in this repository are MIT unless a header says otherwise.
