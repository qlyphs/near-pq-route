What the PQ version changes.

The protocol keeps its code, its state and its users. Only the admin path moves, from accounts held by classical keys to a Guardian that has none.

See it on a real contract →
  • The contract adds one ruleAdmin methods and upgrades accept only the Guardian as caller.
  • The Guardian holds no keysIt acts only on two of three ML-DSA-87 approvals of the exact operation, verified on chain.
  • Every action waits in publicAn on-chain delay leaves time to see it and cancel it before anyone can execute.
  • What it does not coverNEAR consensus, users' own keys, and roles a tile does not read. Guardian is an unaudited testnet prototype.

Public data read live from NEAR mainnet at a finalized block; each tile names its block. No protocol listed here uses Guardian or is affiliated with Qlyphs. A PQ version is what the same contract would look like if its own governance handed its admin to a Guardian.
